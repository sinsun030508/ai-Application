# 설비 고장 예측 — 피지컬AI응용 데이터 분석 프로젝트

센서 5개(공기온도·공정온도·회전수·토크·공구마모)로 밀링 머신 고장을 예측한다. 모델은 결정트리 하나.
데이터: [AI4I 2020 Predictive Maintenance Dataset](https://archive.ics.uci.edu/dataset/601/ai4i+2020+predictive+maintenance+dataset) (UCI, Kaggle 에도 공개 · 합성 데이터)

## 파일

| 파일 | 내용 |
|---|---|
| `설비고장예측_분석.ipynb` | 분석 코드 (코드 칸 6개 · 약 40줄) — 실행 결과까지 저장돼 있다 (제출용 소스코드) |
| `설비고장예측_발표.pptx` | 발표 자료 6장 — 발표자 노트에 대본 |
| `발표대본.md` | 대본만 따로 (약 5분) |

## 제출 순서

1. **코랩 공유 주소** — [colab.research.google.com](https://colab.research.google.com) → 파일 → 노트북 업로드 → `설비고장예측_분석.ipynb`
   → 런타임 → 모두 실행 (데이터는 URL 로 읽어서 업로드할 파일이 없다) → 공유 → "링크가 있는 모든 사용자" 로 바꿔 주소 복사
2. **설명 영상** — PPT 표지에 이름·학번을 넣고, 슬라이드 쇼 → 녹화 → 발표자 노트를 보며 읽기 → 파일 → 내보내기 → 비디오 만들기(mp4)
3. 노트북(또는 코랩 주소)과 mp4(또는 유튜브 주소)를 올린다

## 결과 요약

트리 깊이는 훈련 데이터 5겹 교차검증으로 골랐다 (F1 최고 = 깊이 10). 시험 데이터 2,000건 · 고장 68건:

| 모델 | 정확도 | 재현율 | F1 |
|---|---|---|---|
| 전부 정상 | 0.966 | 0.000 | 0.000 |
| 결정트리 (깊이 10) | 0.981 | 0.647 (44건) | 0.698 |

혼동행렬: 헛경보 14건 · 놓친 고장 24건. 특성 중요도는 토크 0.38 > 공기 온도 0.24 > 공구 마모 0.14.
